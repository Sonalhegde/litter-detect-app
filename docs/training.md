# Training

The application uses the supplied custom YOLO26s checkpoint. The project notes record a 109-epoch training run and approximately 4.24 hours of training, with the selected checkpoint near epoch 89. These values describe the supplied project notes; they are not a new benchmark generated by this web application.

For a reproducible study, record the dataset revision, exact class map, train/validation/test split, random seed, image size, augmentations, optimizer, hardware, software versions, full command, and checkpoint checksum. The original dataset source, complete command, seed, and hardware log were not included in the supplied archive and remain **pending documentation**.

Ultralytics’ official training recipe is available at [YOLO26 training recipe](https://docs.ultralytics.com/guides/yolo26-training-recipe). Official COCO metrics must not be presented as custom marine-litter metrics.
