# Future work

Future work includes expanding the dataset and debris taxonomy, performing an automatic dataset-quality audit with human review, evaluating YOLO26n/m/l/x under one locked protocol, and benchmarking deployment latency across CPU and GPU hardware. Additional product directions include video detection, real-time webcam input, drone footage, underwater cameras, temporal tracking, instance segmentation, marine-scene classification, ONNX/TensorRT export, edge-device deployment, H200 benchmarking, model distillation, and quantization.

These items are proposals, not completed capabilities. Each model comparison should report the same test split, confidence policy, image size, hardware, and latency measurement method.
